خطوات بناء النسخة النهائية (installer.exe)
=============================================

1) جهّز الفولدر
----------------
انسخ الملفات دي الأربعة فوق المجلد الحالي عندك (استبدال):
   - desktop_app.py
   - desktop_app.spec
   - installer.iss
   - requirements.txt

سيب زي ما هو: logo.ico, logo.png, assets/, templates/

2) ثبّت المتطلبات (مرة واحدة بس، أو لو مش متأكد)
--------------------------------------------------
افتح PowerShell جوه المجلد، واكتب:

    python -m pip install -r requirements.txt

3) امسح أي بناء قديم (مهم، عشان التعديلات الجديدة تتضمن فعلاً)
------------------------------------------------------------------
لو عندك فولدرات قديمة اسمها build أو dist، امسحهم الأول:

    Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue

4) ابني البرنامج (PyInstaller)
---------------------------------
    pyinstaller desktop_app.spec

هياخد شوية وقت. لو خلص صح، هتلاقي فولدر جديد اسمه dist\desktop_app فيه
desktop_app.exe وكل الملفات المطلوبة.

5) جرّب الـ exe قبل ما تعمل installer (مهم جداً، خطوة متقفزهاش)
------------------------------------------------------------------
افتح dist\desktop_app\desktop_app.exe بنفسك وجرب:
   - يفتح تمام (من غير شاشة بيضا أو تهنيج)
   - تسجيل الدخول
   - إضافة مريض
   - وضع الصيانة

لو فيه أي مشكلة هنا، متكملش للـ installer، قولي الأول.

6) ابني الـ Installer (Inno Setup)
-------------------------------------
افتح installer.iss بـ Inno Setup Compiler (لو مش مثبت عندك:
https://jrsoftware.org/isdl.php)، ودوس Build (أو F9).

الناتج هيبقى في فولدر Output باسم:
    3R_Pediatric_Clinic_Setup_v1.1.exe

7) جرّب الـ installer نفسه
-----------------------------
ثبّته على نفس الجهاز (أو جهاز تاني لو متاح) وجرب نفس اختبارات الخطوة 5
كاملة من البداية، شاشة "أول تشغيل" هتظهر لأنها نسخة جديدة.

ملاحظات مهمة
--------------
- شاشة Windows SmartScreen هتظهر تحذير "Windows protected your PC" عند
  أول تشغيل عند أي عميل، لأن الملف غير موقّع رقمياً (code signing
  certificate). ده طبيعي ومتوقع، والحل الوحيد شراء شهادة توقيع (مكلفة
  نسبياً للمشاريع الصغيرة)، مش حاجة ينفع تتعمل دلوقتي. لو حابب، قولّي
  نتكلم عنها بعدين كخطوة منفصلة.
- برامج الأنتي فيروس ممكن برضه تحذر من exe غير موقّع، ده متوقع وطبيعي
  لبرامج جديدة مش شائعة، وغالباً هيزول تلقائياً بعد فترة استخدام.
